# 种子表（`0.2.0-rc.2` 快照）

> 中文 ｜ [English](seed-table.en.md)

浏览器里 `require` 只解析到 shell 启动时冻结的这张平台种子表。

## 当时查到的成员

| 模块 id | 说明 |
|---|---|
| `react` | React 运行时 |
| `react/jsx-runtime` | JSX runtime（手写 `createElement` 时用不到） |
| `react-dom` | ReactDOM |
| `react-dom/client` | `createRoot`（**探针的锚点**：表就在它附近） |
| `@deepseek-ai/cordis` | Cordis 运行时 |
| `@deepseek-ai/dsh-client-store` | 客户端 observable store |
| `@deepseek-ai/dsh-client-ui-slots` | 槽位核心 |
| `@deepseek-ai/dsh-client-ui-primitives` | 宿主控件（动态模块包的隐式基线 external） |
| `@deepseek-ai/dsh-client-ui-dockkit` | dock 相关控件 |

## 怎么在自己版本上重查

```sh
# 1) 解前端的 dist（见 _tools/asar-extract.js）
node _tools/asar-extract.js "<安装目录>/resources/app.asar" \
  "/dsh/node_modules/@deepseek-ai/dsh-web-frontend/dist" "_ref/web-frontend-dist"

# 2) 种子表是主 bundle 里一个 id → 模块 的对象字面量，用锚点搜出来
grep -o 'react-dom/client[^}]*}' _ref/web-frontend-dist/assets/index-*.js | head -c 1200
```

**不要把上表当接口用**：新增/移除成员是本表最常变的部分。
本版本 `ui-primitives` 在表内（是动态模块包的隐式 external），但这不保证下个版本仍在——
真正稳定的只有"**先查表、再解构、解构前核对导出存在**"这三步。

## 另一张表不要混用

`Builtin.listBuiltins` 列的是 **`cordis-client-runner` 闭包**（agent 动态写 UI 的那条 lane）
能拿到的注入：`ctx` / `React` / `host` / `styles` / `console`。
那是第三个 lane 的口径，**与种子表不是一回事**。
