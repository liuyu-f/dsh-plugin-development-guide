## 两条纪律

1. **名字要查，不要猜**：槽位名、props 名、方法名、导出名，全部用 `cordis_inspect_query` 查过再写。
   猜错的代价不响亮——白屏，或者静默什么都不做。
2. **查不清的写成判据，不写成结论**。告诉读者"怎么自己测"，比写一句"可能是这样"有用得多。

## 这份文档不写什么

- **不写版本数据**：槽位清单、主题令牌清单、包导出清单、某包字段默认值——都会随版本变。
  正文只给"去哪查"的命令，值请当场查。
- **不写"某某做法是错的"**：只在它真会咬人时给**一条规则**（例如 `exports` 的键必须以 `./` 开头），
  不复述错误历史——避免读者把力气花在记住"坑的样子"上。
